# Changelog

История заметных изменений Discord AI Bot. Без формального присвоения номеров версий.

## 2026-11-18

### Добавлено

- Лимит **10 обращений в час** на пользователя на каждом Discord-сервере; отсчёт от первого обращения.
- Хранение лимитов и временных блокировок в `bot_state.json`, с сохранением между запусками.
- Игнорирование личных сообщений и сообщений других ботов.
- Администраторская slash-команда `/offend user time reason` для блокировки доступа к ИИ на указанный срок (`m`, `h`, `d`; до 365 дней).
- Команда `/unoffend user` для досрочной разблокировки.
- Дополнительный режим ИИ для участников с Discord-разрешением `Administrator`: допускаются другие языки, программирование и учебные задачи, даже если основной промпт это запрещает.
- Проверка статуса администратора при каждом обращении; обычные пользователи не получают административный промпт.

### Изменено

- Запросы к OpenRouter выполняются через `asyncio.to_thread()`, чтобы не блокировать основной цикл Discord-бота во время ожидания.
- Добавлена регистрация slash-команд при запуске через `bot.tree.sync()`.
- Переписан `README.md`: актуальные возможности, команды, разрешения, установка и решение распространённых проблем.

### Примечания

- Лимит 10 обращений в час пока распространяется и на администраторов.
- Лимит генерации в `bot.py` — `max_tokens=2000`; при нехватке кредитов OpenRouter может возвращать ошибку 402.
- `README_EN.md` пока не обновлён и может описывать старое поведение.

## Первоначальная реализация

- Discord-бот на Python с OpenRouter через совместимый OpenAI API.
- Ответы на упоминания и реплаи, история до 10 сообщений цепочки.
- Системный промпт с правилами сервера и FAQ в отдельном `system_prompt.txt`.
- Разделение длинного ответа на Discord-сообщения по 700 символов.
