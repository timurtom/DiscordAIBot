# Discord AI Bot

Русский | [English (старая версия)](./README_EN.md) · [Changelog](./CHANGELOG.md)

Discord-бот на Python с ИИ через [OpenRouter](https://openrouter.ai/). Изначально создавался для Minecraft-сервера: отвечает на вопросы игроков, использует правила и FAQ из системного промпта и поддерживает диалоги через реплаи.

## Возможности

- Отвечает на **упоминания** и **реплаи на свои сообщения** в каналах сервера.
- Передаёт ИИ цепочку до **10 сообщений** из реплаев для контекста.
- Загружает инструкции, правила и FAQ из `system_prompt.txt`.
- Ограничивает каждого пользователя **10 обращениями за 1 час** на каждом сервере. Отсчёт начинается с первого обращения; неудачный запрос к API тоже засчитывается.
- Игнорирует личные сообщения и сообщения других ботов.
- Позволяет администраторам временно блокировать доступ к ИИ и снимать блокировки.
- Для участников с Discord-разрешением **Administrator** добавляет специальную инструкцию к ИИ: разрешает отвечать на других языках, писать код и помогать с заданиями. Это инструкция модели, поэтому абсолютной гарантии выполнения нет.
- Сохраняет лимиты и блокировки в `bot_state.json`, в том числе после перезапуска.

## Команды

| Команда | Назначение | Доступ |
| --- | --- | --- |
| `/offend user time reason` | Заблокировать доступ к ИИ на время | Administrator |
| `/unoffend user` | Досрочно снять блокировку | Administrator |

Пример: `/offend @Player 2h Спам`.

Время задаётся в формате `30m` (минуты), `2h` (часы), `7d` (дни), максимум — `365d`. Блокировка ограничивает только обращения к ИИ, **не** блокирует сообщения человека в Discord.

Обычные пользователи продолжают получать основной промпт; статус администратора проверяется **для каждого обращения** по разрешению `Administrator`, а не по названию роли. Лимит 10 обращений в час действует и на администраторов.

## Установка

### 1. Discord и OpenRouter

1. Создайте приложение и бота в [Discord Developer Portal](https://discord.com/developers/applications).
2. Во вкладке **Bot** получите токен и включите **Message Content Intent**. `Presence Intent` и `Server Members Intent` не нужны.
3. При установке приложения на сервер используйте scopes `bot` и `applications.commands`.
4. Выдайте боту **View Channels**, **Send Messages** и **Read Message History** в нужных каналах. **Embed Links** можно добавить для отображения ссылок. Права **Administrator** самому боту не нужны.
5. Создайте API-ключ в [OpenRouter](https://openrouter.ai/settings/keys). Наличие бесплатных моделей и условия тарификации зависят от выбранной модели и аккаунта.

### 2. Python

Нужен Python 3.10 или новее. Для Debian/Ubuntu:

```bash
sudo apt update
sudo apt install -y git python3 python3-venv
git clone https://github.com/timurtom/DiscordAIBot.git
cd DiscordAIBot
python3 -m venv .venv
source .venv/bin/activate
pip install -U discord.py openai python-dotenv
```

### 3. Конфигурация

Скопируйте примеры переменных окружения и промпта:

```bash
cp example.env .env
cp system_prompt_example.txt system_prompt.txt
```

Если `system_prompt.txt` уже настроен, **не перезаписывайте** его. Укажите в `.env`:

```dotenv
DISCORD_TOKEN=токен_бота
OPENROUTER_API_KEY=ключ_openrouter
OPENROUTER_MODEL=deepseek/deepseek-chat
```

Имя модели — пример: выберите модель, доступную вашему аккаунту в OpenRouter. Не публикуйте `.env` и токены в Git.

Запустите бота из папки проекта:

```bash
python3 bot.py
```

При успешном входе появится `Logged in as ...`. Для остановки используйте `Ctrl+C`.

## Структура проекта

| Файл | Для чего |
| --- | --- |
| `bot.py` | Discord-события, OpenRouter, лимиты и команды |
| `system_prompt.txt` | Инструкции, FAQ и правила сервера |
| `.env` | Токены и выбор модели (секретный файл) |
| `bot_state.json` | Лимиты и блокировки; создаётся автоматически |
| `example.env` | Пример настроек |
| `system_prompt_example.txt` | Пример системного промпта |
| `CHANGELOG.md` | История изменений |

У процесса бота должны быть права **записи в директорию с `bot.py`**, иначе он не сможет сохранять `bot_state.json`. Добавьте `bot_state.json`, `.env` и `.venv/` в `.gitignore`, если их там ещё нет.

## Частые проблемы

**Команды `/offend` и `/unoffend` не отображаются.** Убедитесь, что бот запущен без ошибок, приложение установлено с `applications.commands`, а настройки команд не запрещают их использование. Скрипт синхронизирует команды глобально через `bot.tree.sync()` при запуске; их появление может быть не мгновенным. Команды по умолчанию доступны администраторам.

**Бот не отвечает на сообщения.** Проверьте токен, Message Content Intent, права на чтение/отправку сообщений и то, что вы упомянули бота или ответили реплаем на его сообщение. В ЛС бот специально не отвечает.

**OpenRouter возвращает ошибку `402`.** У аккаунта недостаточно кредитов для выбранной модели и запрошенного лимита ответа. В `bot.py` сейчас используется `max_tokens=2000`. Можно уменьшить это значение (например, до `500`), выбрать более дешёвую модель или проверить баланс. Длинный `system_prompt.txt` и история переписки тоже расходуют входные токены.

**Бот отвечает `чето наебнулось`.** Смотрите текст ошибки в консоли: это общий ответ при ошибке запроса к модели или отправки ответа.

## Ограничения и нюансы

- Ответ нейросети делится на части по **700 символов**, если он длиннее этого значения. Это не лимит в 2000 символов.
- Настройка `max_tokens` ограничивает **токены генерации**, а не символы Discord-сообщения.
- Режим администратора меняет инструкции для модели, но не отключает лимит сообщений и не снимает блокировки автоматически.
- Данные `bot_state.json` хранятся локально; перед переносом бота на другую машину скопируйте файл, если хотите сохранить ограничения.
