# Дискорд бот со встроенным ИИ
RU | [EN](./README_EN.md)

## Вопросы

### Что это такое?
Ну если по названию еще не понятно, это дискорд бот в который встроенный ИИ ассистент
> бот написан на пайтоне если что

### Для чего написан этот бот?
Бот щас пишется на не большой майнкрафт дискорд сервер чтоб игроки могли с ним общатся, хз
По задумке он должен быть ботом с которым можно: пообщатся, задать вопрос по серверу, попросить помощь по майнкрафту и т.п


### Почему именно openrouter?
Потому что бесплатно ¯\\\_(ツ)\_/¯

## Ограничения
Единственные ограничения это то что ему нельзя писать код и ответ не может быть дольше 2000 символов

## Как его установить?
### 1 Часть ( В браузере ) 
1. Открываете [Discord Developer Portal](https://discord.com/developers/home) и создаете там нового бота
2. В вкладке "Бот" создаете токен и копируете на будущее
3. В той же вкладке включаете Presence Intent, Server Members Intent и Message Content Intent
4. Откройте [OpenRouter API key](https://openrouter.ai/workspaces/default/keys), создайте и скопируйте API ключ
### 2 часть ( На сервере )
Устанавливаете все необходимые пакеты
На дебиан/убунту
```
apt update && apt install git python3 python3-pip -y
```
Клонируйте репозиторию и устанавливайте все необходимые библиотеки
```
git clone https://github.com/timurtom/DiscordAIBot.git
cd DiscordAIBot
pip install discord.py openai python-dotenv
```
Переименуйте `example.env` в `.env` и добавьте свои API ключи, переименуйте `system_prompt_example.txt ` в `system_prompt_example.txt`
```
mv example.env .env
mv system_prompt_example.txt system_prompt_example.txt
```
